# Security Policy

**Supported versions:** v1.x (security fixes where practical).

If you discover a potential vulnerability, do **not** post working exploit details, credentials or internal manifests in a public issue. Prefer the **Report a vulnerability** / private security advisory feature of this repository. If unavailable, contact the maintainer using their GitHub profile and request a private reporting channel.

Include version/commit, impact, minimal redacted reproduction, expected versus actual behavior and affected platforms. Do not include live cluster credentials or secrets. Maintainers will assess and coordinate a fix and disclosure. No guaranteed response SLA is promised.

The project is an *offline RBAC policy review tool*, not a certification or a replacement for real-cluster authorization checks.
